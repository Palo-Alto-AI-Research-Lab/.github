## Кратко

Правила простые: уважай людей, спорь с идеями, а не с личностями; не публикуй
чужие персональные данные; не переходи на оскорбления. Нарушения разбираем
быстро и без публичного позора — пиши в issues репозитория
[`.github`](https://github.com/Palo-Alto-AI-Research-Lab/.github/issues), а если
дело личное — открой private security advisory в том репозитории, где всё
случилось. Меры по нарастающей: замечание → предупреждение → временный бан →
постоянный бан.
