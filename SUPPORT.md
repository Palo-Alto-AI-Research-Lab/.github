# Getting help

_Default support page for every public repository of the Palo Alto AI Research
Lab. A repository with its own `SUPPORT.md` overrides this one._

## Where to ask

| You want to | Go here |
|---|---|
| Report a bug or ask "how do I…" | **Issues** of the repository in question |
| Ask about the lab, not a project | [Issues in `.github`](https://github.com/Palo-Alto-AI-Research-Lab/.github/issues) |
| Report a security problem | **Security → Report a vulnerability** (see [SECURITY.md](SECURITY.md)) |
| Propose a change | A pull request — see [CONTRIBUTING.md](CONTRIBUTING.md) |

Please do not use a security advisory for ordinary questions, and do not use a
public issue for security problems.

## Response

We read every thread and answer in it — including "no, and here is why".
Silence is a bug on our side; ping the thread if we go quiet.

## What this is

An independent, self-funded lab: one founder and a fleet of AI agents, building
in public and giving the method away. There is no support contract, no SLA and
no paywall — what you get is an honest answer from the people who actually built
the thing.

Not ready to write code? A good issue, a star, or telling one person who needs
this helps just as much.

## Где спросить (RU)

Баг или вопрос по проекту — **Issues** нужного репозитория. Вопрос про
лабораторию в целом — [issues в `.github`](https://github.com/Palo-Alto-AI-Research-Lab/.github/issues).
Проблема безопасности — вкладка **Security → Report a vulnerability**, публичный
issue для этого не годится. Отвечаем в треде всегда, в том числе «нет, и вот
почему».
